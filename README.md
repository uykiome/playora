# Playora - Компьютерлік ойындар каталогы

# Goal
PHP және MySQL қолданып әзірленген компьютерлік ойындар каталогы. Пайдаланушылар ойындарды іздеп, жанр бойынша сүзе алады, ал тіркелген қолданушылар өздеріне ұнаған ойындарды "Таңдаулылар" тізіміне сақтай алады.
 
# Structure
games.php                # Ойындарды басқару, қарау және жою панелі
add_game.php             # Жаңа ойын енгізу беті (Create)
edit_game.php            # Ойын мәліметтерін өзгерту беті (Update)
index.php                # Басты бет (Ойындар каталогын көрсету және іздеу)
login.php                # Жүйеге кіру (Пайдаланушыны авторизациялау)
register.php             # Тіркелу беті (Жаңа аккаунт ашу)
game.php                 # Ойын туралы ақпарат (Толық мәліметті көрсету)
favorites.php            # Таңдаулылар (Таңдалған ойындарды көрсету)
logout.php               # Жүйеден шығу скрипті (Сессияны жабу)
